# KisanMind AI 🌱

### Your Farm. Your Data. Smarter Decisions.

KisanMind AI is a Telugu-first Agentic AI Farming Intelligence
Platform designed to help farmers make informed farming decisions.

## Project Vision

Build an AI-powered agricultural decision-support platform
that combines farm data, verified agricultural knowledge,
weather intelligence and AI agents.

## Initial Target Users

- Farmers in Andhra Pradesh
- Farmers in Telangana

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- LangChain
- LangGraph
- Qdrant
- Next.js
- Docker
